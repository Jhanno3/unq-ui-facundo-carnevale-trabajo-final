# unq-ui-facundo-carnevale-trabajo-final

Palabras Encadenadas — Trabajo Final Integrador de UIs.

## Requisitos

- Node.js 20 o superior
- npm

## Instalación

```bash
git clone https://github.com/Jhanno3/unq-ui-facundo-carnevale-trabajo-final.git
cd unq-ui-facundo-carnevale-trabajo-final
npm install
```

## Ejecución local

```bash
npm run dev
```

La aplicación queda disponible en `http://localhost:5173`.

## Scripts disponibles

- `npm run dev`: levanta el servidor de desarrollo con hot reload.
- `npm run build`: genera el build de producción en `dist/`.
- `npm run preview`: sirve el build de producción localmente.
- `npm run lint`: corre el linter sobre el código.
